# CineGBA 创作者工作台 · 界面样本 V1 草案

按《CineGBA IP-Bridge 平台网站界面设计方案 V1.0》第 5、6、9、14 节实现的界面样本，用于团队内部讨论。

**在线预览**：<https://706617514-blip.github.io/cinegba-workbench/>

## 里面有什么

四个可切换的页面：

| 页面 | 对应方案 |
|---|---|
| 工作台（仪表盘） | 第五节 |
| 上传作品与生成存证 | 第六节 |
| 作品详情 · 存证信息 | 第九节 |
| 收入中心 | 第十四节 |

右上角两个按钮：

- **深色 / 浅色** —— 方案指定的深黑蓝+青色，与现有品牌纸色体系并排对比
- **评审标注** —— 叠加 12 个红点，点开看每一处改动的理由（手机上直接点红点）

## 三处主要改动

1. **存证信息页**：方案只列区块链记录，改为「链上存证 / 作品自愿登记（DCI）/ 可信时间戳」三路并列，每条写明效力边界。原因是香港没有区块链存证的法定推定规则。
2. **收入中心**：把「实时自动分账」降级为「准实时 60 秒拉取」，结算方式明确区分自动与人工。智能合约分账、香港提现、实时结算在 MVP 阶段都做不了。
3. **全部指标卡**：补上口径说明（是否含待结算、是否已扣佣金）。方案原文没有定义。

## 关于数据

页面里的作品名、金额、编号、机构全部是虚构的，仅用于呈现布局与信息密度，**不代表任何真实业务**。

## 技术说明

单文件 HTML，无外部依赖，无后端，无统计脚本。直接用浏览器打开 `index.html` 即可离线运行。
