# CineGBA IP-Bridge · 创作者工作台原型

可真实操作的原型。**不是静态样稿**：上传会真的把文件写进电脑文件夹，所有编辑都会持久化，刷新和重启都不丢。

## 怎么跑

```bash
cd cinegba-proto
node server.mjs
```

然后打开 **http://localhost:8090**

换个端口：`node server.mjs --port 9000`

## 数据存在哪

启动本地服务后：

| 内容 | 位置 |
|---|---|
| 你上传的原始文件 | `cinegba-proto/data/uploads/` |
| 作品、授权、询价、收入、宣发数据 | `cinegba-proto/data/db.json` |
| 账号（邮箱 + 加盐哈希） | `cinegba-proto/data/users.json` |
| 登录会话 | `cinegba-proto/data/sessions.json` |

**直接打开 `public/index.html`（不走服务）也能用**，但会降级成浏览器存储：上传的文件存在浏览器 IndexedDB 里，换设备或清缓存就没了。页面右下角有个角标会告诉你当前是哪种模式，点它可以看详情。

## 询价是怎么自动化的

采购方不描述场景，只勾 **8 个权利维度**（媒介 / 地域 / 期限 / 独占 / 修改权 / 训练用途 / 转授权 / 署名）。

创作者在作品管理 →「自动策略」里为每件作品设一个**放行区间**：

- **区间内** → 系统按基准价 × 条款系数算价，直接生成订单，不经过创作者
- **超出区间** → 转人工，但精确告诉创作者是哪一维超了，其余条款已锁定

四种**条款包**可一键套用：标准商用 / AI 训练 / 全渠道发行 / 衍生开发。

**飞轮**：某个维度被创作者手动接受满 3 次后，策略页会提示「放宽这一维」。人工处理量因此随时间下降，而不是线性增长。

## 三个分区

登录后顶栏切成三个区，侧栏跟着变：

| 分区 | 里面有什么 |
|---|---|
| **素材市场** | 网站主页、素材市场（6000+ 件）、素材详情 |
| **创作者中心** | 工作台、作品库、上传存证、宣发、收入、**维权**、设置 |
| **消费者中心** | 消费者首页、我的收藏、选购车、我的订单 |

市场分区会自动收起侧栏，让素材网格占满宽度（和 iStock 一样，筛选放在页面内）。

### 5000 件虚拟素材

五种类型（视频 / 图片 / 音频 / 剧本文档 / 3D 模型），每类 **950–1400 件之间确定性随机**（同一类型每次启动一致，彼此不同），当前合计约 6,300 件。

这些**不写进 state**，每次启动用固定种子重建，所以同一个 id 永远指向同一件作品，也不会撑大存档。虚拟素材可以点进详情、选授权、加入选购车、下单，和真实素材走同一套流程。

市场页每页 24 件，支持类型 / 授权方式 / 价格筛选和四种排序。

## 哪些是真操作，哪些是模拟

演示时请照这个说，别把模拟的部分说成真的。

### 真实生效

- **登录 / 注册 / 退出**：密码 scrypt 加盐哈希，服务端校验，会话 token，受保护接口未登录返回 401
- **文件上传**：真的写进 `data/uploads/`，能通过 `/api/files/<id>` 读回原文件
- **数据持久化**：所有编辑写进 `data/db.json`
- **授权配置**：加授权、改价、开关、删除，立刻反映到授权市场
- **询价闭环**：市场提交询价 → 出现在工作台待办 → 回签生成合约与入账记录
- **上架条件校验**：没存证、没授权、含肖像未补文件时，上架会被拦下并说明原因
- **结算与提现**：待结算转已结算，累计数字跟着变
- **宣发**：发布后写进数据，市场推荐位与曝光数字跟着变
- **导出**：收入明细 CSV、维权证据包 CSV、存证凭证 TXT、全量数据 JSON

### 模拟

- **忘记密码**：原型不发邮件，点开会提示直接用演示账号或重新注册
- **指纹哈希、链上交易号、区块高度、时间戳**：随机生成，没有真实的区块链或 TSA 接入
- **推广物料**：只给占位，不生成真实图片文件
- **文件预览**：视频/音频不做抽帧，图片类才有真预览
- **跨设备**：本地服务的数据库只有一份，没做多端同步

## 目录

```
cinegba-proto/
  server.mjs           本地服务（零依赖）
  prerender.mjs        把各视图导出成静态快照，用于视觉检查
  data/
    db.json            数据站（自动生成）
    uploads/           上传的文件
  public/
    index.html         外壳
    styles.css         样式（深色 / 浅色双主题）
    data.js            种子数据
    core.js            存储适配、认证、上传、路由、UI 组件
    views-a.js         工作台 / 上传 / 作品库
    views-b.js         作品详情与管理 / 市场详情
    views-c.js         市场 / 宣发 / 收入 / 维权 / 设置
    views-d.js         落地页 / 登录 / 注册
    views-e.js         网站主页 / 素材市场 / 详情 / 消费者中心 / 选购车 / 订单
    virtual.js         5000 件虚拟素材生成器（固定种子，不写存档）
    app.js             启动与全局交互
```

## 视觉检查

这台机器没有可自动化的浏览器，所以用预渲染做静态核对：

```bash
node prerender.mjs /tmp/snap --desktop   # 桌面布局快照
node prerender.mjs /tmp/snap --mobile    # 手机布局快照
```

生成的 HTML 内联了样式，可以直接用任意浏览器或预览工具打开。
